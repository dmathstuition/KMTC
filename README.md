# ClassCharts Clone Interface

A lightweight front-end clone-style interface inspired by ClassCharts, built with plain HTML, CSS, and JavaScript.

## Features

- Sidebar navigation and teacher profile block
- Dashboard summary cards (attendance and behaviour snapshots)
- Seating plan grid with randomized seat assignment button
- Recent behaviour activity panel
- Responsive layout for desktop and tablet/mobile widths

## Run locally

Open `index.html` in your browser.
